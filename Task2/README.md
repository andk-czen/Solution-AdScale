Проектирование сервиса ставок (Bidding service) для интеграции с новой DSP-площадкой.
Сервис ставок (Bidding service) - первый извлекаемый и монолита сервис. Сервис реализует интеграцию с новой площадкой, находится на критическом пути и влияет на итоговые SLA всей системы.

**Пакет документов содержит:**
- описание границ сервиса, api, зависимости от других сервисов и описание модели данных (bidding-service)
- схему взаимодействия с обовнованием выбора протоколов, протоколы и паттерны взаимодействия (interaction)
- дизайн API-gateway для сервиса DSP (API-gateway)
- диаграммы взаимодействия (sequence)
