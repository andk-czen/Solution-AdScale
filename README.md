# Задание 1. Архитектурная диагностика и целевое видение

**Объект обследования:** компания AdScale - SaaS-платформа для размещения цифровой рекламы.
**Цель бизнеса:** обеспечить интеграцию AdScale с крупной DSP-площадкой в указанные сроки с указанными показателями качества и заложенным бюджетом.
**Предмет обследования:** архитектура компании, технические возможности для реализации бизнес целей.

В рамках задачи проведен анализ текущей архитектуры, выявлены проблемы и риски, разработано целевое архитектурное видение и описана целевая архитектура для компании 

Основные действующие лица бизнес процесса: 
- рекламодатели (запуск рекламной кампании, управление бюджетом, участие в аукционах, аналитика, формирование отчетности)
- пользователи (потребители контента), просматривающие рекламу
задокументированы ключевые решения через ADR
