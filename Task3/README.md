#Данные, масштабирование и отказоустойчивость
**Пакет документов содержит**
Описание проекта данных в микросервисной архитектуре AdScale: выбор хранилищ по сервисам, масштабирование, кэширование, потоковая обработка и отказоустойчивость. 

**Состав документов:**
- database-strategy.md — выбор базы данных для каждого сервиса; стратегию данных для каждого сервиса
- scaling.md — стратегии репликации и шардирования;
- caching.md — дизайн кэширования;
- event-streaming.md — архитектура Kafka;
- diagrams/ — диаграммы данных.
